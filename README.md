## 📖 About This Repository

This is my personal Java learning repository. I am following the **[Java Tutorial For Beginners](https://youtube.com/playlist?list=PLsyeobzWxl7pe_IiTfNyr55kwJPWbgxB5)** playlist by **Navin Reddy (Telusko)** on YouTube — a comprehensive 107-video course covering Core Java from the ground up.

Every folder in this repo corresponds to a **topic from the playlist**. As I finish watching a video and writing the code, I commit it here. This repository documents my entire Java learning journey.

> 📺 **Playlist:** [Telusko — Java Tutorial For Beginners](https://youtube.com/playlist?list=PLsyeobzWxl7pe_IiTfNyr55kwJPWbgxB5)
> 👨‍🏫 **Instructor:** Navin Reddy | Telusko
